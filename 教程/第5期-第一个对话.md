# 第5期：第一个对话

## 视频信息
- **时长**：8-10 分钟
- **目标**：完成第一次对话

---

## 开场（20秒）

哈喽大家好，欢迎回到 OpenClaw 教程系列。

上期我们配置好了 OpenClaw，今天来讲——**如何开始第一个对话？**

---

## 控制台对话（3分钟）

### 打开控制台

```bash
openclaw dashboard
```

然后访问：`http://127.0.0.1:18789/`

### 发送消息

在输入框输入：`你好`

等待回复...

---

## 快捷命令（2分钟）

### 查看状态
```bash
openclaw status
```

### 查看帮助
```bash
openclaw help
```

### 常用快捷键
- `/help` - 查看帮助
- `/status` - 查看状态
- `/quit` - 退出

---

## 对话示例（3分钟）

### 基础对话

```
你：你好
OpenClaw：你好！有什么我可以帮你的？

你：帮我查下北京天气
OpenClaw：北京今天天气晴朗，气温 15-25°C...

你：帮我记个笔记，今天很重要
OpenClaw：好的，我已经记在记忆中了...
```

### 设置人设

```
你：我的名字叫张三
OpenClaw：好的，我记住了！

你：我最喜欢的颜色是蓝色
OpenClaw：已记录，你喜欢蓝色。
```

---

## 工作目录（2分钟）

### 重要文件

| 文件 | 作用 |
|------|------|
| `SOUL.md` | AI 人设 |
| `USER.md` | 用户信息 |
| `MEMORY.md` | 长期记忆 |
| `memory/` | 每日记录 |

### 查看文件

```bash
cd ~/.openclaw/workspace/
ls -la
```
