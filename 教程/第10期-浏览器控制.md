# 第10期：浏览器控制

## 视频信息
- **时长**：12-15 分钟
- **目标**：安装并使用浏览器控制技能

---

## 开场（20秒）

哈喽大家好，欢迎回到 OpenClaw 教程系列。

今天来讲——**如何让 AI 帮你控制浏览器？**

---

## 浏览器控制介绍（3分钟）

可以做到：
- 打开网页
- 填表单
- 点击按钮
- 截图
- 抓取数据

---

## 安装步骤（3分钟）

```bash
openclaw skills install browser
```

需要安装 Playwright：

```bash
playwright install chromium
```

---

## 使用示例（5分钟）

### 打开网页

```
帮我打开百度
```

### 填表单

```
帮我搜索 "OpenClaw"
```

### 截图

```
截取当前页面
```

---

## 注意事项（2分钟）

- 需要安装浏览器
- 首次启动较慢
- 建议使用 Chromium
