## 硬件要求（3分钟）

### 最低配置

| 配置 | 要求 |
|------|------|
| CPU | 1 核 |
| 内存 | 512 MB |
| 存储 | 1 GB |
| 系统 | Node.js 22+ |

### 推荐配置

| 配置 | 推荐 |
|------|------|
| CPU | 2 核以上 |
| 内存 | 1-2 GB |
| 存储 | 10 GB |
| 系统 | macOS / Linux / Windows |

---

## 设备选择（4分钟）

### 1. 个人电脑（推荐）
- ✅ macOS / Linux / Windows
- ✅ 性能强，功能全
- ✅ 适合开发调试

### 2. 虚拟机 / VPS
- ✅ 云服务器（阿里云、腾讯云）
- ✅ PVE / ESXi 虚拟机
- ✅ 7×24 小时运行

### 3. 路由器（极限玩法）
- ✅ 性能有限
- ✅ 可以运行基础功能
- ⚠️ 需要 ARM 架构 + 较大内存

**实测设备：**
- 树莓派 4B（4GB）✅
- N1 盒子 ✅
- 软路由（OpenWrt）✅

---

## 网络要求（2分钟）

### 必须
- 互联网连接
- 能访问 GitHub（下载安装包）

### 可选
- 公网 IP（需要接收 QQ/微信消息时）
- 域名 + HTTPS（可选）

### 内网穿透方案
- Cloudflare Tunnel
- FRP / ngrok
-tailscale
