## 开场（20秒）

哈喽大家好，欢迎回到 OpenClaw 教程系列。

上期我们安装好了 OpenClaw，今天来讲——**如何进行首次配置？**

---

## 配置选项（2分钟）

运行 `openclaw onboard` 会提示配置：

1. **API Provider** - 选择 AI 模型
   - Anthropic (Claude)
   - OpenAI (GPT)
   - MiniMax（推荐国内用户）
   - Ollama（本地模型）

2. **Gateway** - 网关设置
   - 本地运行
   - 远程连接

3. **Channels** - 通讯渠道（可选）
   - QQ
   - Telegram
   - Discord

4. **Skills** - 安装技能

---

## 演示配置（8分钟）

### Step 1：运行引导

```bash
openclaw onboard
```

或跳过手动配置：

```bash
openclaw onboard --install-daemon
```

### Step 2：选择 API

**推荐国内用户：**
- MiniMax（国内访问快）
- API Key 容易获取

**配置示例：**
```
选择 provider: mini-max
输入 API Key: xxx
```

### Step 3：测试对话

在控制台发送：`你好`

---

## 手动配置（3分钟）

如果错过引导，可以手动配置：

```bash
# 查看配置
openclaw configure

# 添加模型
openclaw providers add mini-max

# 设置默认
openclaw configure --default-model mini-max
```

---

## 配置示例（2分钟）

### MiniMax 配置

```bash
# 环境变量方式
export MINIMAX_API_KEY="your-key"

# 或配置文件中设置
```

### 查看可用模型

```bash
openclaw models list
```

---

## 验证配置（1分钟）

```bash
# 重启网关
openclaw gateway restart

# 发送测试消息
openclaw message send --channel control-ui --message "测试"
```
