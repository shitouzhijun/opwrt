---

## 安装方式（2分钟）

### 方式一：一键安装脚本（推荐）

**macOS / Linux / WSL2：**
```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

**Windows (PowerShell)：**
```powershell
iwr -useb https://openclaw.ai/install.ps1 | iex
```

### 方式二：npm 安装

```bash
npm install -g openclaw@latest
openclaw onboard --install-daemon
```

---

## 演示安装（5分钟）

### Step 1：打开终端

macOS：Command + Space → 输入 terminal
Linux：Ctrl + Alt + T
Windows：WSL2 终端

### Step 2：复制粘贴安装命令

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

### Step 3：等待安装完成

- 自动下载 Node.js
- 自动安装依赖
- 自动配置

### Step 4：运行引导

首次运行会提示配置：
- API Key（可选）
- 网关设置
- 通讯渠道

---

## 安装验证（2分钟）

### 检查状态
```bash
openclaw status
```

### 启动网关
```bash
openclaw gateway start
```

### 打开控制台
```bash
openclaw dashboard
```

然后访问：`http://127.0.0.1:18789/`

---

## 常见问题（2分钟）

### Q1：安装失败？
- 检查网络能否访问 GitHub
- 尝试换代理

### Q2：Node 版本不对？
```bash
node --version
# 需要 22+
```

### Q3：权限问题？
```bash
sudo curl -fsSL https://openclaw.ai/install.sh | bash
```
