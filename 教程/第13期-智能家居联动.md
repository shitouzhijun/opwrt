## 开场（20秒）

哈喽大家好，欢迎来到实战应用篇章。

今天来讲——**如何用 OpenClaw 控制智能家居？**

---

## 支持的设备（3分钟）

- 小米米家
- 飞利浦 Hue
- Home Assistant
- 智能灯泡
- 空调伴侣

---

## 配置步骤（5分钟）

### 安装技能

```bash
openclaw skills install homeassistant
# 或
openclaw skills install hue
```

### 配置连接

在配置文件中添加设备信息。

---

## 使用示例（4分钟）

### 控制灯光

```
把客厅灯打开
把卧室灯调暗一点
```

### 控制空调

```
把空调调到 26 度
```

### 场景联动

```
离家模式：关闭所有灯
回家模式：打开客厅灯
```
