---

## 天气技能介绍（2分钟）

内置技能，无需额外安装。

支持：
- 当前天气
- 3天预报
- 空气质量

---

## 使用方法（4分钟）

### 直接询问

```
北京天气怎么样？
上海明天天气如何？
泰兴后天有雨吗？
```

### 命令行方式

```bash
openclaw weather beijing
```

---

## 技能配置（2分钟）

天气技能默认使用 wttr.in，无需配置。

如需自定义：

```bash
# 查看配置
openclaw skills config weather
```
