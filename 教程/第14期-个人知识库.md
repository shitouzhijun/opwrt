## Obsidian 介绍（2分钟）

- 免费开源的笔记软件
- 基于 Markdown
- 支持双向链接
- 插件丰富

---

## 配置步骤（5分钟）

### 1. 安装 Obsidian CLI

```bash
brew install yakitrak/yakitrak/obsidian-cli
```

### 2. 配置 OpenClaw

```bash
openclaw skills install obsidian
```

### 3. 连接 vault

设置 Obsidian vault 路径。
