## 定时任务类型（3分钟）

### 1. Cron 定时任务

```bash
openclaw cron add "0 7 * * *" "天气查询"
```

格式：`分 时 日 月 周 命令`

### 2. Heartbeat 心跳检查

编辑 `HEARTBEAT.md` 文件，设置周期性检查任务。

---

## Cron 任务示例（4分钟）

### 每日早上 7 点查天气

```bash
openclaw cron add "0 7 * * *" "北京天气"
```

### 每周一早上汇总

```bash
openclaw cron add "0 9 * * 1" "周报"
```

### 查看任务

```bash
openclaw cron list
```

---

## Heartbeat 配置（3分钟）

编辑 `HEARTBEAT.md`：

```markdown
# 定期任务

- 检查邮件（每小时）
- 天气提醒（每天早上）
- 新闻摘要（每天早上）
```
